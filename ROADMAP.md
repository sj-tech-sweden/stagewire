# Features

- [x] Add outputs to channellists
- [x] Stage plot finished (device-driven): mandatory device linking on patch points & outputs, device-level Stockwire products, cables routed on the plot with cableways + length list (CSV export), uploaded element images shown on both the main and mini plot, patch-sheet rendering.
- [x] Add wiremaps with easy ways to follow a wire
- [x] Add a way to export console patch and naming and such to a console using different kinds of plugins for each mixer and a additional csv/excel default plugin.
  - We want to start with files for Allen & Heath QU, CQ and GLD after the generic.
- [x] Add generic PDF reports with registry-seeded English and Swedish templates for the audio job summary, channel list, and stage plot. Admins can edit/duplicate templates in a freeform drag-and-resize WYSIWYG editor, insert registered data fields/tables, preview PDFs, and upload/calibrate PDF letterheads. Future report definitions must provide complete English and Swedish names, descriptions, fields, tables, and default content in `api/app/domains/reports/registry.py`; both language defaults are seeded at startup.
- [x] Truncate notes with a readmore toggle if more than two rows
- [x] Stockwire integration both for adding products to a job from selecting a microphone with/without stand, DI and so on. But also to select the mixer and get the correct number of inputs and busses, it should also be possible to suggest a mixer based on a channellist with a certain number of inputs and outputs.
  - The stockwire integration should also make it possible to deeplink both from stagewire to stockwire and stockwire to stagewire and create a job in the other platfrom after it is created in one.
- [x] Make it mobilefriendly with cards instead of table rows on phones and moving the list of channellists and such so that it also works on phones.
- [x] Video suite: inputs and outputs with patch chains, ports per step, splits and passthroughs, per-device patch sheets and signal flow.
- [x] Cameras and lenses: sensor width from aspect ratio and diagonal (with presets), focal range, camera coverage with range or chosen focal length, recommended maximum distance.
- [x] Projectors and screens: throw ratio and aspect, projector cone with screen fit or wall projection, projectors fed from output chains.
- [x] Stage plot reports and the report layout preview draw cables, cableways, audience, speaker, camera and projector coverage the same way as the plot.
- [ ] Pixel map and LED wall for the video suite.
- [ ] Stockwire fields for projectors (`proj_throw_ratio_min/max`, `proj_aspect_ratio`), pending agreement in `docs/stockwire-integration-spec.md` §3.7.
- [x] Lighting fixture patch: universe, address, fixture type, mode, footprint, location, gel, purpose; DMX overlap and channel 512 checks; CSV and MVR import; device weight and power, with Stockwire values.
- [x] Lighting fixtures on the stage plot and in a registry-seeded fixture patch PDF (EN/SV).
- [x] Rigging and power (Phase 3b), shared with sound and video: trusses with weight capacity, distros and circuits, weight loading, circuit load and phase balance, on a Rigging & power tab.
- [ ] Rigging drawn on the stage plot itself (truss positions and hung loads).
- [ ] Stockwire fixture profile fields (fixture type, modes, footprint), pending agreement in `docs/stockwire-integration-spec.md` §3.9.
